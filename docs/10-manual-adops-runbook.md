## フェーズ2：名前・広告グループ名・予算を直す（★本人確認なしで通る）

1. コピーしたキャンペーンの**名前**にマウスを乗せる→**鉛筆**→ 上の表の名前に変更 → チェック/Enterで保存。

## フェーズ4：各広告の中身を入れて保存する（★保存で本人確認＝あなたが完了できる）
広告を1本ずつ開いて（鉛筆/編集）、次を入れる：

| 項目 | 入れるもの |
|---|---|
| 広告名 | 表の「広告」列（例 ytCR_ken-kobetsu-yt-01） |
| 最終ページURL | 表の「LP」（例 https://studio.shokunin-movie.com/ken-kobetsu-01 ） |
| 動画 | YouTube URL貼付（例 https://youtube.com/shorts/-7Qp1VK3m1w ） |
| 広告見出し／長い広告見出し／説明文 | **既存広告と同じ内容**（下の「コピーの入れ方」参照） |
| ビジネス名 | カイジ編集局 |

**入れ終えたら、そのまま「保存」まで押す**（再読込しない）。
保存時に **Googleの本人確認** が出たら、画面の指示に従って完了（これはオーナーのあなたができる操作）。

### コピー（見出し・説明文）の入れ方
「既存広告と同じ内容」にするので、手打ちより**流用**が速くて確実：
- **B（hana）**：お手本の hana キャンペーンを複製したので、**コピーは既に正しい hana の文言が入っています**。→ B は基本、**動画とLPだけ差し替え**ればOK。
- **A / C / D**：別タブで対応する既存広告を開く（A=既存 ken-kobetsu / C=既存 studio-hanatalk-new-yt-01 / D=既存 ken-seminar 系）→ 見出し・長い見出し・説明文を**コピペ**して持ってくる。
- もっと速い技：既存の「その系統の広告」自体を**コピー→貼り付け**して、動画とLPだけ差し替える。

> ⚠️ もし手打ちする場合の景表法ルール：「稼げる／必ず／誰でも／月◯万」等はNG。カイジは**"監修"表記のみ**。
> 既存流用ならこのルールは既にクリアされています。

6. **何も出なければタグが抜けている** → そのLPはまだ公開しない（計測タグの追加が必要）。
